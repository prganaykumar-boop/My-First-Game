# My-First-Game

A tiny Minecraft-inspired sandbox written in Python with `pygame`.

## Features
- Procedural side-view block world.
- Move, jump, and collide with terrain.
- Break blocks with left click.
- Place blocks with right click.
- 5-slot hotbar (`1-5`) for different block types.

## Setup
```bash
python -m venv .venv
source .venv/bin/activate
pip install pygame
```

## Run
```bash
python minicraft.py
```

## Controls
- `A` / `D`: move
- `SPACE`: jump
- `Left Mouse`: break block
- `Right Mouse`: place selected block
- `1-5`: switch hotbar block
